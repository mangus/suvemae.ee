# Kollane agent

A very hard top-down horror game. You are an agent in a yellow hazmat suit, sent into a dark facility to destroy it.

- The game starts with **LIGIPÄÄS - ANTUD!**
- Find the keycards **L1–L6**; each one opens the door with the same number.
- Plant charges (bombs and chemicals) at four targets: Reaktor, Kemikaalihoidla, Serveriruum and Tuum. Stand next to a target until its ring is full.
- When all four are planted, run back to the exit (VÄLJA) before the facility blows up.
- The agent has one life and three nerves. Every jumpscare costs a nerve; with no nerves left the game shows **MÄNG LÄBI!** and *Agendi staatus: Teadmata*.
- Monsters wander the rooms and hunt you once they see you, and something can appear out of nowhere in the dark behind you.

Controls: arrow keys or WASD, on a phone drag a finger anywhere on the game. Your best time is kept in this browser (`localStorage`).
