KOLLANE AGENT

Sina oled agent kollases kaitseülikonnas. Sinu ülesanne: hävita rajatis.

  • Leia läbipääsukaardid L1, L2, L3, L4, L5, L6. Kaart avab sama numbriga ukse.
  • Pane laengud (pommid ja keemilised ained) nelja sihtmärgi juurde: seisa sihtmärgi kõrval, kuni ring saab täis.
  • Kui kõik laengud on paigas, jookse tagasi väljapääsu juurde enne plahvatust.
  • Sul on 1 elu ja 3 närvi. Iga äkkhirmutus võtab ühe närvi. Kui närvid otsas, on elu läinud.
