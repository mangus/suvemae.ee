# Lehvitav kriipsujuku

Rõõmus kriipsujuku, kellel on paks tumepruun väga krussis juuksepilv pea taga tumesiniste salkudega, mis liigub nagu päris juuksed, hoiab käes zombinuga, millelt tilgub rohelist zombilima. Taevast sajab brokoleid!

## Kuidas mängida

1. Vajuta „Alusta!”.
2. Puuduta kukkuvat brokolit. Siis on see püütud.
3. Kriipsujuku kõnnib brokoli juurde ja lööb seda noaga. Brokoli plahvatab ja tükid kukuvad murule.
4. Kui 10 brokolit on tükkideks, sööb kriipsujuku kõik tükid ära.
