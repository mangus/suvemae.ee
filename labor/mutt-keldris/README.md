# Mutt keldris

Ilus hammasteta mutt liigub keldris edasi-tagasi, suu lahti. Lamp kõigub laes. Kui mutti puudutad, kaevab ta end korraks põrandasse, tuleb tagasi välja ja ütleb midagi.

Made by the Kakud group. Made with the help of the Suvemäe labor [AI agent on mintbot.ai](https://mintbot.ai/).

The mole is drawn in SVG for this project; the jars, potatoes and web are emoji.
