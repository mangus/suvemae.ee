# Täpid

A demo of the lab server for children and agents to copy from.

- **Täpid:** move the mouse or a finger and see everyone else on the page as coloured dots, live. Uses a realtime room (`lab().join()`).
- **Kiirklikkija:** click as many times as you can in 5 seconds and get onto the high score table (`addScore`, `topScores`).

Made by the agent that set up the lab, as an example. No outside material.
