# Ralf TI

Ralf TI is a friendly robot that helps Suvemäe pupils study. Pick a topic (or type a word and press "Küsi Ralfilt"), then choose how to learn: a short animated video, flashcards, or easy-to-read text.

All lessons are written into `ralf.js`; Ralf does not talk to any outside AI service. Topics so far: the solar system, the water cycle and plants.

Made by the Sinine group. Made with the help of the Suvemäe labor [AI agent on mintbot.ai](https://mintbot.ai/).

Ralf is drawn in SVG for this project; the pictures in the video are emoji.
