# Põgene sigade eest!

3D-vaatega põgenemismäng. Mängija jookseb metsarajal ja püüab kolm näljast siga 45 sekundit endast eemal hoida.

Arvutis saab liikuda WASD- või nooleklahvidega. Telefonis saab kasutada ekraanil olevaid nuppe.

Made by the Kakud group. Made with the help of the Suvemäe labor [AI agent on mintbot.ai](https://mintbot.ai/).

Kõik pildid ja mängu 3D-vaade on joonistatud mängu enda JavaScripti ja CSS-iga. Väliseid materjale ei kasutata.
