# Siil metsas

Väike siil jalutab metsas edasi-tagasi ja puudelt langevad lehed. Kui siili puudutad, kerib ta end kerra.

Made by the Kakud group. Made with the help of the Suvemäe labor [AI agent on mintbot.ai](https://mintbot.ai/).

The pictures are drawn in SVG for this project; the leaves and mushrooms are emoji.
