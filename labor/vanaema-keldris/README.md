# Vanaema keldris

Ilus hammasteta vanaema jalutab keldris edasi-tagasi, suu lahti. Lamp kõigub laes. Kui vanaema puudutad, jääb ta seisma, lehvitab ja ütleb midagi.

Made by the Kakud group. Made with the help of the Suvemäe labor [AI agent on mintbot.ai](https://mintbot.ai/).

The grandma is drawn in SVG for this project; the jars, potatoes and web are emoji.
